# Amazon UI Clone 🛒

A frontend clone of Amazon's e-commerce website, developed using **HTML5 and CSS3**. This project focuses on recreating Amazon's user interface with a clean layout, product sections, navigation bar, and responsive design elements.

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic elements.
- **CSS3** – Styling, layouts, Flexbox, transitions, and hover effects.

## ✨ Features

- Amazon-inspired navigation bar.
- Search bar UI.
- Product categories and shopping sections.
- Product cards and promotional banners.
- Hover effects and CSS transitions.
- Clean and organized layout.
- Amazon-inspired visual design.

## 💻 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/m-mudassir-hassan/amazon-ui-clone
   ```

2. Open the project folder.

3. Open `index.html` in your browser or use VS Code Live Server.
